# Teaching Channel dashboard reflow mockup

Visual prototype for reviewing the dashboard at 400% browser zoom.

The dashboard reflows into a single column at narrow widths. Product, app,
and video menus are interactive previews with keyboard support. All assets
are local; no sign-in or live platform connection is used. Menu selections
do not change an account or send data to the Teaching Channel platform.

Open `index.html` or use the GitHub Pages deployment. Set browser zoom to 400%
to review reflow; 1280 CSS pixels at 100% corresponds to approximately 320 at 400%.

This is a mockup for review, not the production Teaching Channel platform.
